Create your repo

Your portfolio will live at username.github.io. Create a public repo with exactly that name:

  • Click Create repo on GitHub below (opens github.com/new)
  • Repository name: username.github.io — replace username with your GitHub username
  • Set it to Public, then create the repository
  • Go to repo Settings → Pages → Deploy from a branch → choose main → Save
